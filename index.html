Jadval yaratishdan oldin har bir ustun (column) qanday turdagi ma'lumotni saqlashini belgilab olishimiz shart: INT — Butun sonlar uchun (masalan: ID, yosh, miqdor). VARCHAR(X) — Matnlar uchun (X — harflarning maksimal soni, masalan, ism uchun VARCHAR(50)). DECIMAL(10,2) — Pullar va qoldiqli sonlar uchun (jami 10 ta raqam, verguldan keyin 2 ta raqam). DATE — Kun/oy/yil uchun. Kelgusi qadamda foydalanuvchilar (users) jadvalini yaratamiz: SQL CREATE TABLE foydalanuvchilar ( id INT AUTO_INCREMENT PRIMARY KEY, ism VARCHAR(50) NOT NULL, email VARCHAR(100) UNIQUE, royxat_sana DATE DEFAULT CURRENT_DATE ); Bu yerdagi kalit so'zlarning ma'nosi: PRIMARY KEY — Bu ustun jadvalning "yuragi". Undagi qiymatlar takrorlanmaydi (ID raqamga o'xshash). AUTO_INCREMENT — Har safar yangi odam qo'shilganda ID raqami avtomatik 1, 2, 3... bo'lib o'sib boradi. NOT NULL — Bu ustunni bo'sh qoldirish taqiqlanadi (ism kiritish majburiy). UNIQUE — Bu ustundagi ma'lumot bazada faqat bitta bo'lishi kerak (ikki kishi bir xil email ishlatolmaydi). 4-bosqich: Jadvallarni o'zaro bog'lash (Foreign Key) Relyatsion (SQL) bazalarning kuchi jadvallarni bir-biriga bog'lashda.
